# vibe-coding

一个可直接在浏览器中运行的 MIDI 自动弹奏项目：上传 `.mid/.midi` 后自动解析并播放。

## 功能

- 上传 MIDI 文件并自动解析（支持常见 Format 0/1/2）
- 自动弹奏多轨道、多通道音符
- 支持鼓轨（channel 10 / percussion）
- 支持播放 / 暂停 / 停止 / 拖动进度
- 支持全局速度倍率（0.5x ~ 2.0x）
- 支持按轨道启用/静音，适配不同琴谱编排模式

## 运行方式

1. 安装依赖（仅用于项目脚手架）

```bash
npm install
```

2. 启动静态服务

```bash
python3 -m http.server 8080
```

3. 浏览器打开：

```text
http://localhost:8080
```

## 兼容性说明

- 解析与时序：使用 `@tonejs/midi`
- 合成与调度：使用 `Tone.js`
- 对复杂 MIDI 的支持策略：
  - 优先保证音符、速度、轨道/通道、基础节拍信息可播放
  - 对不同乐器族进行合成器映射，尽可能还原不同琴谱模式
  - 受限于浏览器实时合成，不保证与专业音源 100% 音色一致
